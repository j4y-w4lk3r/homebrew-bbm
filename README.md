# homebrew-bbm

Homebrew tap for [`bbm`](https://github.com/j4y-w4lk3r/bbm) — Backblaze B2 manager.

## Install

```bash
brew tap j4y-w4lk3r/bbm
brew install bbm
```

## Bumps

This tap is auto-maintained: every `git tag vX.Y.Z` on the upstream `bbm`
repo runs goreleaser, which renders `Formula/bbm.rb` and pushes it here
under `bbm-release-bot`. Don't hand-edit the formula — re-tag upstream
instead.

See [j4y-w4lk3r/bbm](https://github.com/j4y-w4lk3r/bbm) for the source.
